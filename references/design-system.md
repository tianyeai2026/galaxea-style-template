## 2. 字体系统

### 字体族
```css
font-family: "Alibaba PuHuiTi", Arial, Helvetica, sans-serif;
```
- 首选：阿里巴巴普惠体（Alibaba PuHuiTi）
- 备选：Arial → Helvetica → sans-serif

### 字号规范
| 层级 | 字号 | 字重 | 行高 | 用途 |
|------|------|------|------|------|
| Hero大标题 | 60px+ | 700 | 1.1 | 首页主标题 |
| 区块标题 | 48px | 700 | 1.2 | section标题 |
| 小标题 | 32px | 600 | 1.3 | 卡片标题 |
| 正文 | 16px | 400 | 1.5 | 段落 |
| 导航链接 | 14-16px | 400 | 64px | 顶部导航 |
| 辅助文字 | 12-14px | 400 | 1.4 | 说明、版权 |
| 咨询热线 | 28-36px | 700 | 1.2 | 页脚电话 |

### 字重
- 400：正文、导航
- 600：小标题
- 700：大标题、强调

## 3. 布局规范

### 导航栏
- 高度：64px
- 定位：fixed top-0 left-0 w-full
- z-index：9999
- 背景：透明 → 滚动后 #272727（0.3s过渡）
- 内边距：左右 40px
- 布局：左Logo | 中导航链接 | 右CTA按钮

### 内容容器
- 最大宽度：1400px（或 container mx-auto）
- 左右内边距：40px（桌面）/ 24px（移动端）

### 全屏滚动（首页）
- 使用 Swiper.js fullpage 模式
- 每屏 100vh
- 切换效果：fade 淡入淡出
- 底部页码指示器：01 02 03...（当前页橙色）
- 右侧/底部滚动指示器

### Section 间距
- 上下内边距：80-120px
- 区块间距：60-80px

## 4. 组件规范

### 按钮
**主按钮（CTA）**
```css
background: #ff5a00;
color: #fff;
border-radius: 8px; /* 或 50px 胶囊形 */
padding: 12px 32px;
font-size: 16px;
font-weight: 500;
transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1);
```
- hover：背景变浅橙或轻微上浮

**次按钮（幽灵按钮）**
```css
background: transparent;
color: #171717;
border: 1px solid #ccc;
border-radius: 8px;
padding: 12px 32px;
```

### 卡片
- 背景：白色
- 圆角：12-16px
- 阴影：0 4px 20px rgba(0,0,0,0.08)
- hover：阴影加深 + 轻微上移

### 右侧社交图标栏
- 定位：fixed，垂直居中，贴右边缘
- 背景：白色
- 圆角：左侧 8px（右贴边）
- 阴影：0 4px 16px rgba(0,0,0,0.12)
- 每个图标：48x48px
- 图标间分隔线：1px solid rgba(0,0,0,0.06)
- 小屏（<768px）隐藏

### 页脚
- 背景：#000
- 上内边距：48px
- 多列布局：5列（产品/平台/关于/更多/联系）
- 列标题：16px 白色 600
- 列链接：14px rgba(255,255,255,0.6)
- 分割线：1px solid rgba(255,255,255,0.1)
- 底部版权：12px rgba(255,255,255,0.4)

## 5. 动画与过渡

### 通用过渡
```css
transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1);
```

### 导航栏
- 背景色过渡：0.3s ease-in-out
- 滚动时从透明变深色

### 滚动进入动画
- 元素从下方淡入上移
- opacity: 0 → 1
- transform: translateY(30px) → 0
- 延迟：按元素顺序递增 0.1s

### 全屏切换
- Swiper fade 效果
- 切换时长：0.8s

## 5.5 隐藏交互效果详解

### 导航栏滚动变色
- 初始状态：背景透明（首页首屏时）
- 滚动超过 50px：背景变为 `#272727`
- 过渡：`background-color 0.3s ease-in-out`
- 实现：监听 `window.scroll`，切换 `.scrolled` class
- 注意：非首页可直接设为深色，不需要透明态

### 汉堡菜单横线动画
- 三条横线，每条 `width: 24px; height: 2px; background: #fff`
- 间距 `my-1.5`（6px）
- 点击后：第一条旋转 45°，第二条消失，第三条旋转 -45°，组成 X
- 过渡：`all 0.3s cubic-bezier(0.4, 0, 0.2, 1)`
- 全屏菜单背景：`#1f1f1f`，覆盖整个视口，z-index 10000

### 全屏滚动（整页锁定）
- 容器：`height: 100vh; overflow: hidden`
- 内容：`transform: translateY(-N * 100vh)`，过渡 `0.8s ease`
- wheel 事件：节流 900ms，防止连续滚动跳多页
- 键盘支持：ArrowUp/ArrowDown/PageUp/PageDown/Home/End
- 触摸支持：touchstart/touchend 计算滑动距离
- 右侧导航点：fixed 右侧，垂直排列，当前页橙色高亮
- 底部页码：显示当前屏名称或编号（01/02/03），可点击跳转

### 深浅背景交替主题色板
- 每屏一套主题，深浅交替，避免视觉疲劳
- 典型 6 套色板循环：
  1. 深色：bg `#0a0a0a`，文字 `#fff`，强调 `#ff6b35`
  2. 浅色：bg `#f5f5f5`，文字 `#171717`，强调 `#ff6b35`
  3. 深色：bg `#1a1a2e`，文字 `#fff`，强调 `#ff9500`
  4. 浅色：bg `#fff8f0`，文字 `#171717`，强调 `#ff6b35`
  5. 深色：bg `#0d1117`，文字 `#fff`，强调 `#ff6b35`
  6. 浅色：bg `#f0f0f0`，文字 `#171717`，强调 `#ff9500`
- 按钮渐变：`linear-gradient(135deg, #ff6b35, #ff9500)`

### 卡片 Hover 上浮
- 默认：`transform: translateY(0); box-shadow: 0 4px 20px rgba(0,0,0,0.08)`
- hover：`transform: translateY(-8px); box-shadow: 0 12px 40px rgba(0,0,0,0.12)`
- 过渡：`all 0.3s cubic-bezier(0.4, 0, 0.2, 1)`

### 按钮 Hover 效果
- 主按钮：背景 `#ff5a00` → `#ff8c42`
- 同时：`transform: translateY(-2px); box-shadow: 0 6px 20px rgba(255,90,0,0.3)`
- 胶囊按钮（大 CTA）：`border-radius: 50px`

### 滚动进入动画
- 使用 IntersectionObserver 监听元素进入视口
- 初始：`opacity: 0; transform: translateY(30px)`
- 进入：`opacity: 1; transform: translateY(0)`
- 过渡：`0.6s ease`，同组元素按顺序延迟 0.1s
- 阈值：`threshold: 0.1`，`rootMargin: '0px 0px -50px 0px'`

### Hero 滚动指示器
- 位于 Hero 屏底部居中
- 鼠标图标 + 向下箭头
- 上下浮动动画：`animation: bounce 2s infinite`
- 提示用户向下滚动

### 右侧导航点（全屏滚动页）
- fixed 右侧，垂直居中偏下
- 每个点：`width: 8px; height: 8px; border-radius: 50%; background: rgba(255,255,255,0.3)`
- 当前页：`background: #ff6b35; transform: scale(1.3)`
- 可点击跳转对应屏
- 深色背景页用白色半透明点，浅色背景页用黑色半透明点

### 社交图标栏悬停
- 默认：图标彩色，白色背景
- hover：背景 `rgba(0,0,0,0.04)`
- 可扩展：hover 时弹出二维码/名片（绝对定位，向左弹出）
- 弹出内容：白色卡片，圆角，阴影，内含二维码图片

## 6. 响应式断点

| 断点 | 宽度 | 变化 |
|------|------|------|
| 桌面 | >1100px | 水平导航菜单 |
| 平板 | 768-1100px | 汉堡菜单，社交栏隐藏 |
| 手机 | <768px | 汉堡菜单，单列布局，社交栏隐藏 |

### 导航响应式
- >1100px：水平排列所有导航链接
- ≤1100px：显示汉堡按钮，点击展开全屏深色菜单

### 布局响应式
- 多列 → 单列（flex-direction: column）
- 大标题字号缩小（60px → 36px）
- 容器内边距缩小（40px → 24px）
